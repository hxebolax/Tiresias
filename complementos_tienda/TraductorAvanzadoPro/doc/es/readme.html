Descripción

Traductor Avanzado Pro traduce textos a decenas de idiomas con varios servicios. Sus funciones principales son:

  • Traducción simultánea de todo lo que dice Tiresias, sin bloquear la voz.
  • Traducción del texto seleccionado, del portapapeles, del último texto verbalizado y del objeto navegador.
  • Ocho servicios: Google Translate, DeepL (gratuito y API oficial), Microsoft Translator, LibreTranslate, OpenAI, Claude, Google Gemini y DeepSeek.
  • OCR con traducción, diccionario multilingüe y detección del idioma.
  • Intercambio automático de idioma: si el texto ya está en el idioma de destino, se traduce al idioma alternativo.
  • Caché inteligente por aplicación e idioma, e historial con búsqueda, filtros, exportación a CSV y JSON y estadísticas.
  • Interfaz de traducción manual con audio (voz de Google) y un reproductor con control de volumen, velocidad y saltos.
  • Varias claves de API por servicio, cifradas, con rotación automática si una falla.
  • Un sistema de plugins para añadir servicios y funciones nuevas.

Requisitos e instalación

  • Tiresias 1.0 o posterior y conexión a internet.
  • Para OCR: un idioma de reconocimiento de Windows (Configuración de Windows, Hora e idioma) o Tesseract, como para el OCR de Tiresias.
  • Para OpenAI, Claude, Gemini, DeepSeek y la API de DeepL hace falta una clave de API propia de cada servicio (suele ser de pago). Google, DeepL gratuito y Microsoft no necesitan clave; LibreTranslate puede necesitarla según el servidor.

Instálalo desde la tienda de complementos de Tiresias o con «Complementos, Administrador de complementos, Instalar desde archivo». Después de instalarlo, reinicia Tiresias.

Por defecto solo hay dos atajos globales (en NVDA eran NVDA+Mayúsculas+T y NVDA+Mayúsculas+I, pero en Tiresias esas combinaciones ya son de «IA: traducir el texto seleccionado» y «Lupa: invertir colores»):

Traducción simultánea

Con la traducción simultánea activada (capa, T), todo lo que dice Tiresias pasa por el traductor mediante el punto de extensión de voz filter_speechSequence:

  • Si la frase ya está en la caché, se dice traducida al momento.
  • Si no, se dice el original y la traducción se pide en segundo plano; en cuanto llega se dice a continuación, sin interrumpir. La voz de Tiresias nunca se bloquea esperando a la red.
  • No se traducen los caracteres y palabras que escribes, los mensajes del propio complemento ni las traducciones que ya ha dicho (así no hay bucles).
  • Las traducciones se muestran también en la línea braille.
  • Al desactivarla se descarta lo pendiente y la caché se guarda en disco.

Claves de API, modelos y prompts

En las Opciones de Tiresias, categoría «Traductor Avanzado Pro», grupo «Claves API», cada servicio que usa clave tiene:

  • Gestionar claves: lista de claves (se muestran censuradas) en el orden de uso, con Subir, Bajar y Eliminar; un campo para añadir una clave nueva; la casilla «Habilitar rotación automática de claves (usar la siguiente si una falla)»; la URL del servidor en LibreTranslate y OpenAI; y en DeepL API el botón para consultar el uso.
  • Configurar (OpenAI, Claude, Gemini y DeepSeek, cuando hay clave): modelo (lista descargada del servicio, que se guarda una semana; «Actualizar lista» la vuelve a pedir; también se puede escribir el nombre), prompt de sistema y prompt de usuario con los marcadores {idioma_destino} y {texto}, y un botón para restablecer los prompts predeterminados.

Las claves se guardan cifradas con la protección de datos de Windows (DPAPI): solo tu usuario, en este equipo, puede descifrarlas. Si copias la carpeta de datos a otro equipo tendrás que volver a escribirlas.

En los diálogos del complemento, Control+H muestra la ayuda del control con el foco.

Opciones

Están en Tiresias, menú Preferencias, Opciones, categoría «Traductor Avanzado Pro» (también con la capa y P, o desde el menú Herramientas). Se guardan con la configuración de Tiresias (y con sus perfiles).

  • General: servicio activo, idioma de origen (o detección automática), idioma de destino e idioma alternativo.
  • Opciones: habilitar caché de traducciones; guardar historial de traducciones; mostrar resultados en ventana (si no, se leen y se muestran en braille); reproducir sonidos; volumen de los sonidos.
  • Avanzado: intercambio automático de idioma si el origen coincide con el destino.
  • Reproductor de audio: volumen, velocidad y tamaño de los saltos al retroceder y adelantar.
  • Servicios: lista de servicios con su descripción, si requieren clave, si está configurada, si detectan el idioma, versión y modelo.
  • Claves API: ver el apartado anterior.
  • Plugins de extensión: casillas para activar o desactivar cada plugin, con su descripción.
  • Información y mantenimiento: versión y carpeta de datos; botones Limpiar caché, Limpiar historial, Restablecer configuración (pone los valores de fábrica; se guardan al pulsar Aceptar; no borra las claves) y Abrir carpeta de datos.

Interfaz de traducción y reproductor

Con la capa y W (o desde el menú) se abre la interfaz de traducción, con el texto seleccionado si lo hay:

  • Alt+1: texto de origen; Alt+2: texto de destino (solo lectura); Alt+3: idioma de origen; Alt+4: idioma de destino; Alt+5: número de caracteres.
  • Botones: Traducir (también Control+Intro), Escuchar, Intercambiar (cambia los idiomas y pasa la traducción al campo de origen), Limpiar, Pegar al foco (pega la traducción en la ventana que estaba activa y restaura el portapapeles) y Cerrar.
  • Los idiomas elegidos se recuerdan para la próxima vez.

«Escuchar» descarga la traducción con la voz de Google (con una barra de progreso que se puede cancelar) y abre el reproductor:

Teclas del reproductor
TeclaAcción
F1Retroceder
F2Reproducir o pausar
F3Adelantar
F4Detener
F5 y F6Bajar y subir el volumen
F7 y F8Bajar y subir la velocidad (de 0,5 a 2)

Mayúsculas+F10 o tecla Aplicaciones en Retroceder o AdelantarElegir el salto: 1, 5, 10, 15 o 30 segundos o 1 minuto

«Guardar audio» guarda el audio como MP3. Volumen, velocidad y saltos se recuerdan.

Historial

Se guardan las 500 traducciones más recientes, también entre sesiones. El diálogo del historial (capa y H) tiene búsqueda, filtros por idioma de destino y por servicio, la lista de traducciones, el texto completo de la seleccionada y los botones Copiar original, Copiar traducción (o Intro en la lista), Eliminar, Exportar (CSV para hojas de cálculo o JSON), Estadísticas (total, caracteres, idioma y servicio más usados, y el estado de la caché) y Limpiar todo.

Caché inteligente

Las traducciones se guardan por aplicación e idioma de destino (como mucho 1000 por grupo; cuando se llena se descartan las menos usadas). Se busca primero en la caché de la aplicación con el foco y después en la general. La caché se guarda en disco cada pocas traducciones, al desactivar la traducción y al cerrar Tiresias. Con la capa: A limpia toda la caché, X la de la aplicación actual y G la activa o desactiva.

Plugins de extensión

  • Traductor OCR (capa, R): reconoce el objeto navegador con el motor de OCR de Tiresias (Windows OCR o Tesseract, con el idioma elegido en sus opciones) y traduce el texto.
  • Diccionario Multilingüe (capa, E): definiciones, fonética, ejemplos, sinónimos y antónimos de la palabra seleccionada, en una ventana navegable y traducidos al idioma de destino. Usa Free Dictionary API y Wiktionary (con palabras de muchos idiomas); si no encuentra la palabra, busca su traducción al inglés.
  • Detector de Idioma Google (Tiresias+Control+Mayúsculas+G o capa, I).
  • Detector de Idioma local, sin conexión (alfabetos y palabras frecuentes), que se usa si Google no responde.
  • Historial Inteligente: exportación, estadísticas y búsqueda avanzada del historial.

Añadir servicios y plugins propios

Los archivos .py que pongas en las carpetas traductores y plugins de la carpeta de datos del complemento se cargan al iniciar Tiresias (y no se pierden al actualizar). Un servicio hereda de TraductorBase:

from ..nucleo.gestor_traductores import TraductorBase

class MiTraductor(TraductorBase):
	id = "mi_traductor"
	nombre = "Mi traductor personalizado"
	descripcion = "Descripción del servicio"
	requiere_api = True

	def traducir(self, texto, idioma_origen="auto", idioma_destino="es", **kwargs):
		# Devuelve la traducción, o None si falla (y pon el motivo en self.ultimo_error)
		return texto_traducido

Un plugin hereda de PluginBase (from ..nucleo.gestor_plugins import PluginBase, TipoPlugin), define id, nombre, descripcion y ejecutar(), y puede exponer comandos con obtener_comandos() y entradas para el submenú del complemento con obtener_elementos_menu() (lista de {"etiqueta": ..., "accion": ...}). Con self.plugin_principal accede al complemento (gestores de traductores, idiomas, caché e historial).

Menú Herramientas

En el menú de Tiresias, Herramientas, Traductor Avanzado Pro: Configuración, Historial de traducciones, Interfaz de traducción, Cambio rápido de servicio e idiomas, Idioma de destino, Idioma de origen, Documentación (este documento) y Apoyar el proyecto.

Dónde se guardan los datos

En la carpeta de datos de Tiresias, addonsData\TraductorAvanzadoPro: apis.json (claves cifradas y ajustes de cada servicio), historial.json, cache (caché de traducciones), modelos (listas de modelos de las IA), temp (audio temporal del reproductor), y las carpetas traductores, plugins y sonidos para tus añadidos (un open.wav o close.wav propio sustituye a los sonidos de la capa). También se puede poner un idiomas.json para añadir o renombrar idiomas.

Diferencias con la versión de NVDA

  • Atajos globales: Tiresias+Control+Mayúsculas+T y Tiresias+Control+Mayúsculas+G (los de NVDA chocaban con órdenes de Tiresias).
  • La configuración es una categoría de las Opciones de Tiresias en lugar de un diálogo propio con pestañas; el menú del complemento está en Herramientas.
  • Se añade el servicio Claude, que la descripción del original citaba pero no traía.
  • Las claves se cifran con DPAPI (el original solo las ocultaba con base64).
  • El historial se conserva entre sesiones y se puede buscar, filtrar, exportar y ver sus estadísticas (en el original el plugin de historial inteligente no estaba conectado).
  • La caché por aplicación funciona de verdad (en el original «limpiar la caché de la aplicación» no encontraba nada).
  • El OCR traduce el texto reconocido (en el original se quedaba en el portapapeles por un fallo).
  • Las teclas D y O de la capa abren una lista de idiomas; C abre el cambio rápido (en el original las tres abrían el cambio rápido).
  • Comprobar actualizaciones consulta la tienda de complementos de Tiresias (en el original era un aviso fijo).
  • El audio se guarda como MP3, que es lo que devuelve Google (el original lo llamaba .wav).
  • El reproductor usa el wx.media que trae Tiresias; no hacen falta las copias de wx.media para Python 3.11 y 3.13 del original.
  • La traducción simultánea no traduce lo que escribes ni los mensajes del propio complemento.
