TCA SystemUtilities

Versión 1.0.0 para Tiresias. Basado en TCA SystemUtilities para NVDA, de Peter Reina (Tecnoconocimiento Accesible), versión 0.12, con el lanzador de consolas de Héctor J. Benítez Corredera.

Este complemento te permite ejecutar rápidamente muchas acciones de Windows sin buscarlas en la Configuración ni en el Panel de control: apagar o reiniciar con el sonido clásico de Windows, entrar en el Modo seguro o en la BIOS-UEFI, reparar el sistema con SFC o DISM, limpiar el disco, analizar con Microsoft Defender, copiar al portapapeles la ruta o la lista de archivos de la carpeta en la que estás, abrir una consola en esa carpeta, ocultar o mostrar archivos y mucho más.

Cómo se usa

Todas las acciones están en tres sitios:

  • Tiresias+Mayúsculas+8 abre el menú de TCA SystemUtilities donde estés. Es la forma más cómoda para las acciones del Explorador: el menú recuerda la ventana del Explorador que estaba activa y la carpeta o el archivo con el foco.
  • El menú de Tiresias, Herramientas > TCA SystemUtilities, con los mismos submenús.
  • El diálogo Gestos de entrada, categoría TCA SystemUtilities: cada acción es una orden a la que puedes asignar la tecla que quieras. Como en el original, ninguna acción tiene tecla asignada de fábrica (solo el menú).

Muchas acciones necesitan permiso de administrador: Windows mostrará el Control de cuentas de usuario y, si no das el permiso, Tiresias te dice que no se ha hecho nada. Las acciones que no lo necesitan (apagar, planes de energía, menú de contexto, abrir programas...) ya no lo piden, a diferencia del original. Cada acción te dice si ha salido bien o no.

Con la sesión bloqueada o en las pantallas seguras no se ejecuta ninguna acción.

Apagado del sistema

  • Apagar y Reiniciar: avisan con un mensaje, suenan con el clásico sonido de cierre de Windows y apagan o reinician en 3 segundos.
  • Anular el apagado o reinicio: anula cualquiera de los dos anteriores. Solo hay 3 segundos para hacerlo, así que conviene asignarle una tecla en Gestos de entrada. Si no hay ningún apagado en curso, Tiresias lo dice.
  • Entrar a la BIOS-UEFI: tras confirmarlo, reinicia el equipo y entra en la configuración del firmware. En la BIOS-UEFI no hay sonido ni lector de pantalla; para volver a Windows sin cambiar nada puedes pulsar Control+Alt+Supr. Solo funciona en equipos con firmware UEFI.
  • Hibernar: pone el equipo en hibernación (si está activada en el equipo).
  • Reiniciar y entrar en Modo seguro con funciones de red: tras confirmarlo, configura el arranque en Modo seguro con funciones de red y reinicia. En ese modo Windows arranca con lo mínimo; sirve para limpiezas a fondo o quitar programas no deseados. En sistemas anteriores a Windows 10 puede que no haya sonido. El equipo seguirá arrancando en Modo seguro hasta que lo desactives.
  • Reiniciar en Modo normal: quita el Modo seguro del arranque y reinicia.
  • Suspender: suspende el equipo (suspensión, no hibernación).

Explorador y procesos

  • Borrar el portapapeles: vacía el portapapeles y borra su historial de Windows 10 y 11 (los elementos anclados se conservan).
  • Cerrar todas las aplicaciones: tras confirmarlo, cierra a la fuerza todas las aplicaciones abiertas del usuario, también las de segundo plano. No se podrán guardar los documentos. A diferencia del original, nunca cierra Tiresias, los lectores de pantalla (NVDA, JAWS, Narrador) ni los componentes de Windows (los programas de la carpeta de Windows, como el Explorador).
  • Cerrar tareas que no responden: cierra los programas cuyas ventanas no responden y dice cuáles.
  • Habilitar menú de contexto clásico y Habilitar menú de contexto tipo: Windows 11: en Windows 11, eligen entre el menú contextual clásico (el de Windows 10) y el nuevo. Se reinicia el Explorador para aplicarlo.
  • Matar procesos: pide el nombre de una aplicación y termina todos los procesos cuyo nombre empieza por lo escrito (por ejemplo, «chrome»).
  • Monitor de recursos de Windows: abre esta herramienta de Windows, un administrador de tareas avanzado.
  • Reiniciar Explorador: cierra y vuelve a iniciar el Explorador de Windows.

Reparación y optimización

  • Activar almacenamiento reservado y Desactivar almacenamiento reservado: el espacio (unos 7 a 10 GB) que Windows reserva para las actualizaciones. No hace falta para que funcionen. Si hay actualizaciones pendientes, Windows no deja cambiarlo hasta reiniciar.
  • Activar el plan alto rendimiento y Activar el plan equilibrado: cambian el plan de energía. Algunos equipos modernos solo tienen el plan equilibrado.
  • Análisis del sistema con SFC: ejecuta sfc /scannow en una consola, que espera una tecla al terminar para que puedas leer el resultado.
  • Limpiar caché DNS: puede arreglar problemas al navegar por Internet.
  • Limpiar configuración guardada en pantallas seguras: tras confirmarlo, borra la configuración de Tiresias copiada para las pantallas seguras (inicio de sesión, Control de cuentas de usuario, Control+Alt+Supr), que vuelven a usar la configuración de fábrica. En Tiresias los complementos nunca se cargan en las pantallas seguras, así que no hay complementos que borrar.
  • Limpiar disco: abre el Liberador de espacio en disco con un perfil de limpieza que limpia todas las unidades. La primera vez aparece un aviso para Crear perfil (marca en él todo lo que quieras limpiar y pulsa Aceptar; la limpieza empieza al cerrarlo), Limpiar sin crear perfil o Cancelar, con la casilla No volver a mostrar este mensaje. Para volver a verlo, activa la opción del complemento (ver más abajo).
  • Optimizar las unidades: abre la herramienta de Windows para desfragmentar y optimizar los discos.
  • Restablecer PC: abre la página Recuperación de la Configuración, donde está «Restablecer este PC».
  • Reparar sistema con Dism: ejecuta DISM /Online /Cleanup-Image /RestoreHealth en una consola.

Seguridad de Windows

  • Activar el control de cuentas de usuario (uac): vuelve a poner el nivel de fábrica de Windows (preguntar cuando un programa quiere hacer cambios).
  • Desactivar el control de cuentas de usuario (uac): los programas obtienen permiso de administrador sin preguntar. Los dos cambios se aplican al momento; solo si el control de cuentas estaba desactivado del todo hace falta reiniciar, y entonces se pregunta si quieres hacerlo.
  • Analizar arranque del sistema, Análisis completo y Análisis rápido: analizan con Microsoft Defender en una consola que muestra el progreso y espera una tecla al terminar. El análisis del arranque revisa el sector de arranque y la carpeta Boot de Windows.
  • Escanear archivos comprimidos y No escanear archivos comprimidos: activan o desactivan el análisis de los archivos ZIP, RAR, etc.
  • Listado de archivos en cuarentena al portapapeles: copia la lista de los archivos que Microsoft Defender ha puesto en cuarentena.

Voz y multimedia

  • Activar Webcam y Desactivar Webcam: activan o desactivan las cámaras del equipo (desactivadas, ningún programa puede usarlas).
  • Opciones de sonido: abre el panel Sonido (Reproducción, Grabación, Sonidos y Comunicaciones).
  • Opciones de voz: abre las propiedades de texto a voz de Windows (voz SAPI predeterminada).

Utilidades del sistema

  • Asistente guardar contraseñas de usuarios: copia de seguridad de las credenciales guardadas de Windows.
  • Asistente transferir archivos por Bluetooth: enviar o recibir archivos por Bluetooth.
  • Carpeta Roaming: abre la carpeta AppData\Roaming del usuario.
  • Asistente para guardar la contraseña del sistema: crea un disco para restablecer la contraseña de Windows.
  • Mapa de caracteres.

Archivos y carpetas (Explorador)

Estas acciones trabajan sobre la ventana del Explorador de archivos (o el escritorio) que esté activa: si no lo está, Tiresias dice «Active una ventana del explorador antes de ejecutar esta acción». En el original solo tenían orden de teclado; en Tiresias están también en el submenú Archivos y carpetas (Explorador). La ruta se obtiene de la propia ventana del Explorador, sin copiar nada al portapapeles.

  • Copiar la ruta: copia la ruta completa (entre comillas) del archivo o carpeta con el foco; si no hay ninguno, la de la carpeta abierta.
  • Copiar la lista de carpetas y archivos: copia los nombres, primero las carpetas y luego los archivos, por orden alfabético y sin los ocultos. Si el foco está en una carpeta, se copia el contenido de esa carpeta; si está en un archivo, el de la carpeta que lo contiene.
  • Abrir CMD en la ruta actual y Abrir CMD como administrador en la ruta actual: en la carpeta con el foco o en la que contiene el archivo con el foco.
  • Lanzador de consolas: una lista con CMD, PowerShell, Windows Terminal y Git Bash (las que estén instaladas), cada una normal o como administrador, que se abren en esa carpeta. Intro abre la elegida y Escape cierra.
  • Ocultar el archivo o carpeta con el foco: le pone el atributo oculto. Si el Explorador muestra los elementos ocultos, lo seguirás viendo.
  • Mostrar archivos o carpetas ocultos: si el elemento con el foco está oculto, lo muestra; si no, muestra los elementos ocultos que hay en esa carpeta (o en la que contiene el archivo con el foco). A diferencia del original, no entra en las subcarpetas ni toca los archivos ocultos de sistema, que Windows protege.

Información al portapapeles

  • Copiar información de todo el sistema: un resumen del equipo (el de systeminfo). Tarda unos segundos; Tiresias avisa cuando está copiado.
  • Copiar información de las tarjetas de sonido: nombre, fabricante y estado de todos los dispositivos de sonido.

Opciones

En Opciones de Tiresias, categoría TCA SystemUtilities: Preguntar si se quiere crear un perfil de limpieza antes de limpiar el disco (activada por defecto). Se desactiva sola al marcar «No volver a mostrar este mensaje».

Diferencias con el original

  • Nuevo menú emergente con Tiresias+Mayúsculas+8 y submenús «Archivos y carpetas (Explorador)» e «Información al portapapeles».
  • Solo se pide permiso de administrador cuando hace falta, y se dice el resultado real de cada acción (el original daba por hecho que todo había salido bien).
  • El Modo seguro es el Modo seguro con funciones de red con el Explorador (el original activaba también la consola como interfaz). «Reiniciar en Modo normal» quita las dos cosas.
  • Activar el control de cuentas de usuario pone el nivel de fábrica de Windows, en lugar del nivel más alto («Notificarme siempre») que ponía el original.
  • La webcam se busca por la clase «Cámara» de Windows además de por el nombre, y no hace falta pulsar Intro para confirmar.
  • Cerrar todas las aplicaciones pide confirmación y no cierra Tiresias, los lectores de pantalla ni Windows.
  • Limpiar la configuración de las pantallas seguras borra la de Tiresias (no la de NVDA) y no reinicia el Explorador, que no hace falta.
  • Se quitan las prácticas del original de pulsar teclas por ti (F5 para actualizar el Explorador, Control+C para obtener la ruta, Intro para confirmar): el Explorador se actualiza solo.
